# 경쟁 글 벤치마킹 · 지시문 개선

사용자가 참고할 만한 글 URL 을 던지면, 그 글이 **왜 잘 읽히는지**를 구조로 분해하고
우리 글과 비교해 `src/prompt.js` 를 고칩니다. 배운 것은 누적해서 다음에 또 씁니다.

목표는 베끼는 것이 아닙니다. **어떤 장치가 독자를 붙잡는지**를 찾아
우리 지시문의 규칙으로 옮기는 것입니다.

## 1. 글 가져오기

`WebFetch` 는 `blog.naver.com` 에서 막힙니다. **Playwright 를 쓰세요.**
네이버 블로그 본문은 `#mainFrame` iframe 안에 있습니다.

```js
const frame = page.frames().find(f => f.url().includes('PostView')) || page.mainFrame();
const body = document.querySelector('.se-main-container');
```

블록 단위 구조는 `.se-component` 를 순회하면 이미지·인용·본문 순서가 그대로 나옵니다.
티스토리는 `#article-view`, 브런치는 `.wrap_body` 를 보세요.

## 2. 분석 항목 — 반드시 수치로

인상이 아니라 **세보고 재세요.** "글이 좋다" 는 개선으로 이어지지 않습니다.

| 항목 | 재는 법 |
|---|---|
| 제목 공식 | 어떤 요소가 어떤 순서로 들어갔는가 (인물·사안·파장·수치) |
| 분량 | 공백 제외 글자수 |
| 문체 | 경어체/평어체, 1인칭 여부, 문장 끝맺음 패턴 |
| 문단 | 평균 문장 수, 빈 줄 사용 |
| 소제목 | 개수, 형태(질문형/요약형/서정형), 이름 포함 여부 |
| 이미지 | 장수, 해상도, 배치 간격, 캡션 유무 |
| 강조 | 굵은글씨·색상 span 개수 |
| 입장 | 판단을 내리는가, 어떤 표현으로 (단정형/추정형) |
| **영상·기사 밖 정보** | 원소재에 없는 정보를 가져왔는가 ← 대개 여기가 승부처 |
| 내부 링크 | 관련글 개수 |

## 3. 우리 글과 비교

가장 최근 발행글을 `out/*.json` 에서 읽어 같은 항목으로 재고 표로 나란히 놓으세요.
**우리가 이미 이기는 항목도 반드시 적으세요.** 그건 건드리면 안 되는 자산입니다.
(예: 우리 장면 캡처는 1920×1080 인데 경쟁 글은 500×300 이었습니다)

## 4. 지시문 고치기

차이 중 **재현 가능한 규칙**만 옮깁니다. 취향 차이는 옮기지 마세요.

- 영상 글 → `buildClipPrompt`, 기사 글 → `buildNewsPrompt`, 주제 글 → `buildArticlePrompt`
- 모드별로 다르게 적용해야 하면 `src/mode.js` 의 `CAPABILITIES` 에 항목을 넣으세요
- 규칙에는 **좋은 예와 나쁜 예를 함께** 쓰세요. 나쁜 예에는 우리가 실제로 냈던
  결과물을 넣으면 효과가 큽니다 (모델이 그 패턴을 확실히 피합니다)
- 지시가 서로 **충돌하지 않는지** 확인하세요. 실제로 "에세이로 쓰라" 와
  "소제목을 검색 질문형으로" 가 충돌해 결과가 매번 리포트가 된 적이 있습니다.
  구조 지시가 문체 지시를 이깁니다.

## 5. 배운 것 누적

`.claude/skills/benchmark-post/references/learned.md` 에 한 줄씩 남기세요.
같은 것을 다시 발견하는 낭비를 막고, 규칙끼리 부딪히는 것도 여기서 보입니다.

```
## YYYY-MM-DD  <출처 URL>
- 발견: (무엇이 달랐는가, 수치로)
- 반영: (prompt.js 의 어느 규칙으로 옮겼는가)
- 보류: (옮기지 않은 것과 그 이유)
```

## 6. 검증

지시문만 고치고 끝내지 마세요. **한 편을 실제로 뽑아 확인**합니다.

```
npm run draft -- "<같은 소재 URL>" --verbose
```

`draft` 는 발행하지 않고 `out/*.preview.html` 만 만듭니다. 발행 전에 이걸로 보세요.
확인할 것: 문체가 바뀌었는가, 소제목이 의도대로인가, 분량이 줄지 않았는가,
그리고 **이전에 고친 것이 되돌아가지 않았는가**.
